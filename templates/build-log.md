# Build Log

The project's institutional memory at the milestone grain: what shipped, why, and what was
learned. **Append-only.** Add entries at the END with an Edit (old_string = the last few
lines, new_string = those lines + your entry) — never rewrite this file with Write, and
check `git diff --stat` shows no deletions before committing.

Milestone numbers are sequential (one per entry, not calendar days). While an
`ORCHESTRATOR ACTIVE` banner stands, the seat allocates N through the board's LOG slot.
