# Agnostic memory starter (25 files) — seeded by bootstrap-project

Portable engineering and process lessons that hold on ANY project, curated from the origin
project's memory store and genericized in v0.4.0. Excluded on purpose: project FACTS, one
person's working preferences (session style, deploy cadence, UI-mockup habits, link
formatting), and anything that encodes a STANDING PERMISSION (a trust grant never ports to a
fresh project by default).

Bootstrap copies these into the new project's memory directory only when that directory does
not exist yet.
